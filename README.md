## 📌 Tính năng nổi bật

1. **VirtualFit: Spatial 3D Try-On Hero**:
   - Trải nghiệm ướm trang phục ảo không gian 3D dạng vòm kính visionOS với hiệu ứng quét scanline AI.
2. **Số hóa tủ đồ (Digital Wardrobe)**:
   - Quản lý và phân loại trang phục đa danh mục (Áo, Quần & Váy, Áo khoác, Giày dép, Phụ kiện).
   - Mô phỏng tách nền AI tự động khi tải ảnh trang phục lên.
3. **Trợ lý phối đồ AI (AI Stylist Assistant)**:
   - Gợi ý 3 bộ trang phục hoàn chỉnh theo bối cảnh thời tiết (Nắng ấm, Mưa rào, Mát mẻ, Se lạnh) và lịch trình (Công sở, Giảng đường, Cuối tuần).
   - Phân tích hòa sắc và tính điểm hòa hợp trang phục.
4. **Nhật ký mặc đồ & Radar chống mua trùng (Wear Log & Anti-Repeat)**:
   - Lưu trữ lịch sử mặc đồ chống lặp trang phục trong các dịp quan trọng.
   - Radar cảnh báo khi chuẩn bị mua trang phục tương đồng với đồ đã có.
5. **Hỗ trợ Song ngữ & Chế độ Sáng / Tối**:
   - Chuyển đổi ngôn ngữ Tiếng Việt (VI) và Tiếng Anh (EN) mượt mà.
   - Chế độ Dark Mode độ tương phản cao, êm dịu cho mắt.

## 🛠️ Công nghệ sử dụng

- **Frontend**: HTML5, Vanilla JavaScript (ES6+), Tailwind CSS (CDN).
- **Typography**: Playfair Display (Serif), Plus Jakarta Sans & Be Vietnam Pro (100% tiếng Việt).
- **Icons**: Lucide Icons.
- **Kiến trúc**: 100% Client-side Static Web (Không cần cài đặt backend hay database).
